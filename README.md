## 🎯 Описание

Игроку необходимо нажать кнопку в нужный момент, чтобы:
- поймать максимальное значение шкалы
- выбить приз (рубин 💎)

Логика игры включает:
- анимацию шкалы
- расчет силы удара
- определение победы / поражения
- визуализацию результата
